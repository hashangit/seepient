# Cookbook overview

The cookbook contains end-to-end recipes for common development, DevOps, and integration scenarios.

---

## Available recipes

- **[GitHub Action PR reviewer](/cookbook/github-action)**: Set up an autonomous CI agent that reviews pull requests, verifies test coverage, and proposes exact code fixes.
- **[React chat UI](/cookbook/react-chat)**: Build a responsive, streaming web chat interface connected to Seepient's WebSocket daemon.
- **[Local LLMs with Ollama](/cookbook/local-llm)**: Run fully offline agents using Ollama and vLLM with automatic fallback to cloud models during high-load periods.
- **[Production checklist](/cookbook/production-checklist)**: Hardening checklist for deploying Seepient safely in production cloud environments.
